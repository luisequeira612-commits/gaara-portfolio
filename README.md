# GAARA — The Sand Guardian

A responsive, cinematic fan-made tribute page for Gaara of the Sand (Naruto).

## Live site
https://luisequeira612-commits.github.io/gaara-portfolio/

## Run locally
Open `index.html` in a browser. No build tools, dependencies, server, or API keys are required.

## Features
- Responsive desktop and mobile layout
- Interactive artwork selector with four Gaara scenes
- Mobile navigation
- Reduced-motion support
- GitHub Pages deployment through GitHub Actions

## Artwork
Character artwork is loaded from external wallpaper/image hosts. Their respective creators and sites retain their rights. This is an unofficial, non-commercial fan tribute and is not affiliated with or endorsed by the Naruto rights holders.
